## สิ่งที่อยู่ในเว็บหน้าบ้าน

| ส่วน | สถานะปัจจุบัน |
| --- | --- |
| `/learning` | หน้าหลัก Pharmacy Academy ใช้รูปแบบเว็บเดิม แสดงหมวดหมู่ คอร์สแนะนำ คอร์สยอดนิยม และส่งคำค้นหรือหมวดหมู่ไปหน้าคอร์สทั้งหมด |
| `/learning/courses` | แสดงคอร์สทั้งหมด ค้นหา กรองหมวดหมู่ คงตัวกรองใน URL โหลดเพิ่มเติม และแสดง empty state พร้อมปุ่มล้างตัวกรอง |
| `/learning/[id]` | หน้ารายละเอียดคอร์สใหม่ แสดงราคา ระยะเวลา CPE เนื้อหา ผู้สอน และปุ่มลงทะเบียน |
| `/learning/checkout` | หน้ายืนยันการลงทะเบียนเต็มความกว้างตามหน้าหลัก รองรับการกดจำลองชำระเงิน ไม่มีการเรียกเก็บเงินจริง |
| การย้อนกลับ | ใช้ข้อความสั้นว่า **ย้อนกลับ** และใช้ history ของเว็บเมื่อมีหน้าก่อนหน้า หากเปิด URL โดยตรงจะใช้ปลายทางสำรอง ลิงก์คอร์สเก็บแหล่งที่มาเพื่อกลับหน้าหลักหรือหน้าคอร์สทั้งหมดพร้อมตัวกรอง |
| ลิงก์ “ดูทั้งหมด” | ใช้ `ViewAllLink` เพื่อให้สไตล์และลูกศรตรงกันในส่วนที่ปรับแล้ว |

การปรับปุ่มย้อนกลับครอบคลุมบางหน้าของข่าว งานประชุม ค้นหาใบอนุญาต โครงการประชาชน โปรไฟล์ และ E-Service ด้วย ไม่ได้จำกัดเฉพาะ Academy

## แหล่งข้อมูลและการเชื่อมต่อ

- ค่าเริ่มต้นของ `lib/academy/client.ts` ใช้ข้อมูลตัวอย่างจาก `lib/academy/mock.ts` ข้อมูลคำสั่งซื้อและการลงทะเบียนจำลองเก็บใน `localStorage` ของ browser ภายใต้ key `pharmacy-academy-mock-v1`
- ตั้ง `NEXT_PUBLIC_ACADEMY_DATA_SOURCE=api` จึงจะเปลี่ยนไปเรียก API โดยผ่าน `/api/academy/*` ใน Next.js โค้ดเชื่อม API ยังอยู่ แต่การใช้งานจริงยังต้องมี backend ที่พร้อมใช้งานและตั้งค่าการยืนยันตัวตน
- Route proxy อยู่ที่ `app/api/academy/[...path]/route.ts` ใช้ `NEXT_PUBLIC_API_URL` เป็นปลายทาง และลงนาม session assertion สำหรับคำขอที่ต้องเข้าสู่ระบบ
- ห้ามถือว่าการจำลองชำระเงินเป็นระบบรับเงินจริง

## ข้อจำกัดที่ต้องทราบ

- งานใน repository นี้ยังไม่ถูก commit หรือ push ตามคำขอให้ตรวจงานก่อน
- ฐานข้อมูลที่ API เดิมใช้มี `pharmacist_logins` และคอลัมน์ `pharmacists.prefix`, `pharmacists.citizen_id` ซึ่งไม่อยู่ใน Drizzle schema ปัจจุบัน การ `drizzle-kit push` แบบรวมเคยเสนอให้ rename หรือลบข้อมูลเดิม จึงยังไม่ควรยืนยันคำสั่งนั้นเพื่อเพิ่ม Academy
- เอกสาร `docs/architecture/pharmacy-academy.md` อธิบายระบบ Academy ต้นทางที่ใหญ่กว่าฟีเจอร์ mock ปัจจุบัน อย่าใช้เป็นหลักฐานว่าฟีเจอร์ทั้งหมดของต้นทางถูกย้ายมาที่เว็บนี้แล้ว
